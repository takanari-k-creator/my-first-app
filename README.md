# my-first-app

このリポジトリは、HTML/CSS/JS を 3 ファイルに分けたサイバーパンク風ネオンデザインの横スクロール MVP ゲームの実装例です。

## 使い方

1. `index.html` をブラウザで開く
2. `← →` で移動
3. `↑ / W` でジャンプ
4. `Space / J` で前方攻撃
5. `K` で後方攻撃
6. `R` でゲームオーバー後に再スタート

## ファイル構成

- `index.html` - ゲーム画面の骨組み
- `styles.css` - 見た目とレイアウト
- `script.js` - ゲームロジックと描画

## 実行時の注意

静的ファイルなので、ローカルで開いても動きます。より実態に近い確認をする場合は、次のコマンドで簡単なローカルサーバーを立てると便利です。

```bash
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開いてください。
